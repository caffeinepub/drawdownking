# Specification

## Summary
**Goal:** Create a responsive single-page marketing website for the DrawdownKing brand that clearly presents its purpose and offerings with a cohesive non-blue-and-purple visual theme.

**Planned changes:**
- Build a single-page layout with sections for Hero (headline, subtext, CTA), Purpose, and Offerings (feature cards).
- Add a header with scroll-to navigation links for the page sections.
- Add a footer with the DrawdownKing brand name and English contact placeholders (no external integrations).
- Apply a consistent visual theme (colors, typography, spacing, component style) across the site, avoiding blue-and-purple as the dominant palette.
- Add and reference static generated image assets (logo + hero illustration/background + icons) from `frontend/public/assets/generated`.

**User-visible outcome:** Visitors can view a polished, responsive DrawdownKing landing page with clear navigation, a branded hero section with CTA, purpose explanation, and offerings presented as cards, including static brand visuals.
